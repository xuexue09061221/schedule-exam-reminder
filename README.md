# 📅 课表 & 考试提醒 —— 大学生 AI 实战作品 #1

> 一个用 AI 编程助手（Codex）从 0 做出来的**单文件网页工具**：打开浏览器就能用，无需安装、数据存本地、可导出备份。
> 适合做你的第一篇「AI 辅助编程」图文/视频素材。

## ✨ 功能一览
- **周课表视图**：周一到周日，8:00–22:00，点击空白格即可快速加课；点击课程块可编辑/删除
- **今日概览**：下一节课倒计时、下一场考试倒计时、今日课程列表
- **考试倒计时**：自动计算「还有 N 天 / 今天 X 小时」并置顶最近一场
- **智能提醒**：开启后可弹系统通知 —— 上课前 N 分钟、考试前 N 分钟提醒（可自己设提前量）
- **本地保存**：数据存在浏览器 localStorage，刷新不丢失；支持一键导出/导入 JSON 备份
- **示例数据**：首次打开自动载入一套示例课表，方便直接体验，点「清空」即可录入自己的

## 🚀 使用方法
1. 用浏览器（推荐 Edge / Chrome）直接打开 `index.html`
2. 点右上角「清空」，再点「＋ 添加课程 / ＋ 添加考试」录入自己的安排
3. 打开页面时保持运行即可收到提醒；手机/平板也能用
4. 重要数据记得「导出」备份

### 想发给同学 / 部署成网址？
- 最简：把 `index.html` 发给对方，双击即用
- 免费部署：上传到 GitHub 仓库 → Settings → Pages（选 main 分支）即可得到一个网址，扫码/点开就能用

## 🛠 我是怎么让 AI 30 分钟做出它的（过程记录 = 你的文章素材）
下面是我实际使用的**提示词流程**，你可以原样参考：

1. **一句话需求**
   > 帮我做一个课表和考试提醒工具，用浏览器就能打开，能添加每周课程和考试日期，自动显示下一节课/下场考试的倒计时，还能在课前提醒我。

2. **让 AI 拆功能 + 确认形态**
   > 请先列出这个工具需要哪些功能模块，并建议用什么样的技术形态最合适（要零安装、本地数据、方便我录屏演示）。

3. **让 AI 写代码**
   > 用单个 HTML 文件实现：CSS 现代化美观、中文界面；课程按星期×时间渲染成周课表；考试列表按日期排序并显示倒计时；数据存 localStorage；支持导出/导入 JSON；默认带一套示例数据方便演示。

4. **AI 自查 + 我实测**
   > 让 AI 检查代码有没有语法问题、时间计算有没有 bug（比如跨天、周末）；再用浏览器打开实测，把发现的问题反馈给它修。

5. **打磨细节**
   > 加一个"现在几点"的红色时间线、今天高亮、配色更年轻好看、加上删除确认，防止误删。

**核心经验（写进文章）**：不要把 AI 当"自动完成机"，要把它当**会写代码的实习生** —— 需求越具体、验收越认真，产出越能直接用。你负责"想要什么 + 检查对不对"，AI 负责"怎么写"。
